# ChalkBored

A study-break notebook for students: lessons and games, Chalk Music, Chalk TV,
Chalk Browser, a Requests poll, themes and tab cloaks.

- https://chalkbored.win
- https://chalkbored-public.vercel.app

This repo is generated. Every file here is written by a script from the
ChalkBored source, so changes made here directly are overwritten on the next
update.

Chalk TV and Chalk Browser use [Tide](https://github.com/Guernica4u/Tide)
(AGPL-3.0, a fork of [GUST](https://github.com/nautilus-os/GUST)) on its public
servers. Requests and the online count use the Supabase project set up by
`SCRIPTS/public-setup.sql`; there are no accounts.
