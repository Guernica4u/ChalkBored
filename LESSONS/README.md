## Not games (shared parts)

| Folder or file | What it is |
|------|------|
| `Flash-Player-2/` | Ruffle 0.7.1 (Flash player) used by most Flash games |
| `Flash-Player/` | Older Ruffle copy, still used by Age of War, Line Rider and Meat Boy |
| `art/` | Card cover pictures |
| `forgecraft.html`, `forgecraft.1.5.html`, `forgecraft.1.12.html`, `forgecraft-26.2/`, `forgecraft-26.3/` | The Eaglercraft versions (1.8, 1.5, 1.12, 26.2, 26.3) that the Eaglercraft launcher opens |
| `Rhythm-Geometry/`, `Stick-Figure-Drawing/`, `Study-Hall/` | Old copies no card points to any more |
| `README.txt` | Old note |

The two big Flash files for BTD4 and Learn to Fly 3 live in `/SWF/` at the top of the repo.
